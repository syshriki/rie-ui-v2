Spacing Guide for Web App
1. Base Unit
Base Unit: Use a base spacing unit of 8px (or 0.5rem, assuming 1rem = 16px). This is a common standard because it scales well and aligns with most device pixel ratios.

All spacing values should be multiples of this base unit (e.g., 8px, 16px, 24px) to maintain consistency.

3. Key Spacing Guidelines
Padding within Components:
Buttons: Use S (8px) or M (16px) padding for comfortable tap targets.

Cards: Apply M (16px) or L (24px) padding inside cards for content.

Modals: Use L (24px) or XL (32px) for internal padding to ensure readability.

Margins between Elements:
Between sibling elements (e.g., buttons in a row): Use S (8px) or M (16px).

Between sections (e.g., header and content): Use L (24px) or XL (32px).

Page-level margins: Use XL (32px) or XXL (48px) for main content containers.

Gutters for Grids:
Use M (16px) or L (24px) for column gaps in grid layouts.

Ensure gutters are consistent across breakpoints (e.g., reduce to S (8px) on mobile if needed).

Line Spacing (Typography):
Line height should be 1.4–1.6x the font size for body text (e.g., 16px font → 22–26px line height).

Use S (8px) or M (16px) for vertical spacing between text elements like headings and paragraphs.

4. Responsive Spacing
Adjust spacing for different screen sizes to optimize usability:
Mobile (≤768px):
Reduce padding/margins by one step (e.g., L (24px) → M (16px)).

Tighten grid gutters to S (8px) or M (16px) to save space.

Tablet (769px–1024px):
Use the standard scale but consider reducing XXL (48px) to XL (32px) for tighter layouts.

Desktop (>1024px):
Use the full spacing scale for maximum clarity.

Increase hero section spacing to XXL (48px) or XXXL (64px) for visual impact.
